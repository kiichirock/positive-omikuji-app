# 🍺 開運みくじアプリ (Positive Omikuji App)

**「とにかく飲む理由が欲しい！」** そんなあなたのための、ポジティブなおみくじアプリです。
全ての結果が「大吉」以上。ラッキーアイテムとして、美味しいビールや発泡酒の銘柄を提案します。

## 🚀 アプリで遊ぶ
**👉 [https://positive-omikuji-app.vercel.app/](https://positive-omikuji-app.vercel.app/)**

↑ここをクリックすると、ブラウザですぐに遊べます！

---

## ✨ 特徴
- **ハズレなし！** 全ての結果が「大吉」（色はランダムで変化）
- **今日の一杯を提案！** 実在するビール・発泡酒・新ジャンル銘柄をラッキーアイテムとして表示
- **飲みたくなるメッセージ！** 居酒屋やお酒にまつわる、約100種類のユニークなメッセージ
- **昭和レトロなデザイン！** 懐かしくて楽しい、ネオ居酒屋風のUI

## 🛠️ 使用技術
- React
- Tailwind CSS
- Lucide React (アイコン)
- Vercel (ホスティング)
